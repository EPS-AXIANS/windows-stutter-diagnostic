WINDOWS STUTTER DIAGNOSTIC — COMPILER PUIS INSTALLER
====================================================

Le programme doit d'abord etre compile sur ce PC. C'est automatique, mais la
PREMIERE compilation echoue presque toujours : il faudra 2 a 4 essais, avec a
chaque fois l'envoi d'un fichier d'erreurs a la personne qui vous guide, qui
corrige et vous renvoie une nouvelle version.


ETAPE 1 — RECUPERER LE CODE
---------------------------
Vous avez recu SOIT un dossier "windows-stutter-diagnostic" (zip a extraire),
SOIT rien : dans ce cas le script tentera de le telecharger tout seul.
Placez ce dossier "deploy" DANS le dossier du projet (a cote de StutterDiag.sln)
si ce n'est pas deja le cas.


ETAPE 2 — LANCER LA COMPILATION
------------------------------
1. Double-cliquer sur :   Build-Windows.bat
2. Laisser faire. Il installe le necessaire (dans votre profil, sans mot de
   passe administrateur) puis compile. Comptez 5 a 15 minutes.

  -> SI VOUS VOYEZ "LA COMPILATION A ECHOUE" :
     Deux fichiers sont apparus dans ce dossier :
        build-errors.txt   (petit)
        build-log.txt      (gros, au cas ou)
     Envoyez-les tous les deux. Attendez une nouvelle version du code, puis
     relancez Build-Windows.bat. Repetez jusqu'a "TERMINE".

  -> SI VOUS VOYEZ "TERMINE" :
     Une fenetre de securite Windows apparait pour installer le service.
     Cliquer "Oui". C'est fini : la surveillance tourne en arriere-plan.
     Le PC s'utilise normalement.


ETAPE 3 — PLUS TARD : RAPPORTS, PAUSE, ETC.
------------------------------------------
Double-cliquer sur :   Lancer-StutterDiag.bat
  1 = (re)installer / mettre a jour
  2 = etat        3 = demarrer        4 = pause
  5 = generer un rapport HTML sur le Bureau (a envoyer)
  6 = ouvrir l'interface
  7 = desinstaller


EN CAS DE SOUCI
--------------
- Faire une photo de la fenetre et l'envoyer.
- Journaux : build-log.txt (compilation) et C:\StutterDiag\deploy.log (installation).
- Rien n'est envoye sur Internet par le programme. Donnees locales dans
  C:\ProgramData\StutterDiag .
